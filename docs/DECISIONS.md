# 重要决策

## 稳定分支与开发分支

协作中以 `main` 为稳定分支，在 `dev-writing` 上开发和测试。这一分工来自当前协作者的明确说明；合并和发布须另有授权。

## 从统一审美转向通用写作基础

Skill 依据文体、语境和作者选择审视表达，不再使用固定词句、标点、材料数量或语言统计作为一票否决条件。事实核验、引文准确和现实与虚构的区分仍然保留。原有脚本的主要价值依赖已取消的机械规则，因此删除，而非保留或重做检查器。此决定影响入口、参考文件、精简版和使用说明；创作效果仍需通过真实任务检验。

## 2026-11-08：独立作者与最小文档托管

用户明确要求：培养与猛犸合作有默契的独立作者，而不是提取其文风或镜像其审美。主要先做视频文案，由 Agent 负责研究、构思、写作和统稿，猛犸负责创作判断，允许随时介入；不设默认逐阶段审批。

先做一套 skill，文档托管作为其中一部分。独立的创作目录由 Agent 维护 AGENTS.md 与当前稿入口，用户可以直接索取稿件或让 Agent 建文档供自己写，不引入 computer use、专用工作台或数据库。

取消“只服务当前作品”的限制，允许有限的跨作品合作经验。记录作品情境、判断依据和来源，不把单次或重复反馈直接固化为审美禁令；经验可修正、淘汰，不自动改写 skill。用户选择先按当前能看见的需求实施，复杂能力等真实使用后再调整。

保留 `human-writing` 目录和调用名以兼容现有用法，显示名更新为「猛犸写作」。直接使用版同步自包含规则，安装仍是可选项；没有文件工具时只能交付文本，不能声称实现本地文档托管。
