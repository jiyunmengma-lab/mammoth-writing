# 项目目标与边界

本项目提供「活人感写作」中文写作 Skill，供使用支持 Skill 的 Agent 的人进行写作和改稿。目标是帮助作品有具体材料、自然中文表达和清晰推进，同时区分现实写作的事实边界与虚构创作的要求。

仓库包含 Skill 入口、按任务读取的参考规则，以及可供聊天窗口使用的精简版。表达方式应尊重文体、语境和作者选择；事实核验与审稿依赖具体内容判断。项目不建立长期作者画像、个人规则库或新的个人写作 Skill；具体行为以 Skill 本身为准。

主要目标成立时，使用者能够按 README 安装并调用 Skill，按任务找到相关规则，并按作品需要进行审稿；现实和虚构任务的边界应按各自规则处理。
