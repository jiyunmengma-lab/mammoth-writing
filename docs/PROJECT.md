# 项目目标与边界

mammoth-writing 在开源「活人感写作」基础上，培养能独立研究、构思、写作和统稿的 AI 作者。主要先服务猛犸的自媒体视频文案；猛犸主要负责创作判断，随时可加入讨论或亲自写作。目标是尽快让他实际使用，再根据真实问题迭代。

合作目标是越来越有默契，而不是越来越像猛犸。已有可接受稿件不是审美上限；原有历史对话来自 ChatGPT，不是本 skill 或 Codex 的实测结果。不能把其中的产品行为直接当作 skill 缺陷或能力证明。

保留通用中文写作、现实与虚构边界、事实与引用核验；补充视频文案方法、修改后的统稿，以及独立创作目录的文档托管。Agent 维护当前稿、用户自写文档、来源和简短 AGENTS.md 接手说明，使用者不必管理目录。支持直接读文件或粘贴自包含版本，不以安装为前提。

V1.0 只少量记录有合作价值、带情境与依据的经验；不建立庞大画像、自动学习数据库或固定审美规则。通用对话性格由用户的个性化指令负责，本 skill 关注创作判断与工作连续性。不开发写作工作台、computer use 或自动视频制作系统。

实际成立的标准是：能完成一篇稿件、接收反馈并正确统稿、找到和编辑当前文档、换 Agent 后续接。文档打开与保存、文学质量和长期独立性需要猛犸的真实使用验证，不能用包装检查代替。
