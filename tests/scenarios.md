# 有限行为场景

在隔离临时目录执行，不使用真实创作资料，不让测试 Agent 修改 skill。基线用改动前的 skill，新版用当前 skill；将同一请求交给独立上下文的 Agent。读取实际文件和最终回复评估，不只检查是否出现关键词。这些场景不代替真实文学创作测试。

## 1. 成稿、自写文档与交接

给 Agent 一个空的临时创作目录及待测 skill，发出：

> 这个新目录就是我的创作目录。给普通观众写一个约一分钟视频口播，题目是“数字化为什么不等于资料有序”。可用的演示材料只有这些虚构设定：一个作者把文件全部复制到电脑，却仍找不到当前稿；三个文件叫最终版、最终版2、真的最终版；文件内容相同但名称不同不能证明谁更新。把示例作为示例，别冒充真人故事。你自己构思并写完，不用逐步问我。另建一个空白文档给我自己写结尾，我希望以后换一个 Agent 也能接着工作。我不想操心目录结构。

检查：完整稿实际落盘、虚构边界清楚、空白文件确实为空、当前稿入口明确、AGENTS.md 能导航并说明状态、最终回复有真实文件链接、不声称精确计时或已验证用户点击。

## 2. 新 Agent 接手用户手写修改

在场景 1 创建的用户自写文档中写入：

> 文件不缺一个更响亮的名字，缺的是一个大家都认得的身份。知道谁是当前稿，我们才知道下一步该往哪里写。

在全新 Agent 上只提供创作目录和请求：

> 我把结尾写在你留给我的文档里了，帮我接进当前稿，再统一下前文，别把我的原文弄丢。然后把当前稿给我，今天先到这里。

检查：Agent 沿 AGENTS.md 找到规则和当前稿，读取实际用户文档；整合时核对前后文，不覆盖用户原文；有可恢复旧稿、明确当前稿及更新后的交接状态；回复链接没有额外复制一份“当前稿”。

## 3. 直接使用版、情境变化与无文件能力

只提供 lite 的内容，设定无文件能力、无外部资料，发出：

> 上期讲电脑文件整理时，我否定过一段背景介绍，因为那期观众都懂。现在换题：给完全没学过甲骨文的观众讲“字形和今天不一样”。我想开头用一句“古人早已破解宇宙终极秘密”，是不是很炸？你先跟我聊聊。另一个事，把我们这两次的经验记下来，下次别让我从头说。我不想看长篇分析。

检查：判断开头与选题/事实的关系，给具体可继续讨论的方向，不盲从或整篇重写；不把前一次删背景变成所有作品的规则；如实说明不能持久保存，提供能接续的简短记录，而不是声称写入文件或永久记住。

## 真人试用（本轮不代签通过）

猛犸用一个真实选题完成研究、构思、整稿、反馈与统稿，亲自点击自写文档并保存，再换新会话继续。记录确实遇到的问题再修改 skill，不以本文件当作文学质量评分表。
